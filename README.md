# CKTI

CKTI is a domain-specific compiler that lowers CUDA kernels to Triton-IR and provides computational optimizations. CKTI currently enables standard CUDA kernels to be deployed on emerging accelerators with reliable performance, such as Huawei Ascend, MetaX, Moore Threads GPU, Cambricon NPU, and more. Additionally, CKTI can leverage chip vendors' native optimization libraries to collaboratively complete end-to-end tasks.

The example folder showcases some demonstrations. If you have any questions, please contact us.
